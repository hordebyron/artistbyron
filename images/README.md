# Hero images — drop real art photos here

The home-page carousel looks for these three files, in this order:
- `hero1.jpg` — Big Paws
- `hero2.jpg` — Lost in Contemplation
- `hero3.jpg` — Rumble Ready

How to swap a placeholder for a real photo:
1. Save the art photo as one of those exact names (JPG is fine, PNG works too if you rename the file in `index.html` to match).
2. Keep each file small for phones — under ~500 KB if you can, and roughly 1200 × 800 pixels or similar.
3. Put it in this `images/` folder, push to GitHub, and the carousel will show the photo instead of the big emoji placeholder. No code change needed.

If a file is missing, that slide just shows its placeholder — the site does not break.
Do not hotlink images from other sites. Only use Byron's own art.
